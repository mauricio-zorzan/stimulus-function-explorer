# Stimulus Function Explorer

A comprehensive web application for exploring and discovering educational stimulus functions with integrated educational standards.

## 🚀 Live Demo

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://stimfunc.streamlit.app/)

## 📋 Features

- **Function Gallery**: Browse all available stimulus functions with visual examples
- **Advanced Search**: Search by function name, category, tags, description, or educational standards
- **Educational Standards Integration**: View CCSS and other educational standards linked to each function
- **AI-Powered Search**: Natural language search capabilities
- **Function Details**: Comprehensive information about each function including parameters, examples, and standards
- **One-Click Sync**: Update functions, images, and standards directly from the app (no cron jobs needed)

## 🛠️ Local Development

### Prerequisites

- Python 3.8+
- pip
- Git (for syncing the coach-bot repository)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mauricio-zorzan/stimulus-function-explorer.git
cd stimulus-function-explorer
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Set up environment variables:
```bash
# Create a .env file with your credentials
DB_USERNAME=your_username          # Optional, for educational standards
DB_PASSWORD=your_password          # Optional, for educational standards
GITHUB_TOKEN=your_github_token     # Optional, for syncing repository
OPENAI_API_KEY=your_openai_key     # Optional, for AI search
```

4. Set up the coach-bot repository and complete the full setup:
```bash
# See SETUP.md for complete step-by-step instructions
# This includes: cloning repo, running tests, syncing functions, and syncing standards
```

5. Run the application:
```bash
streamlit run app_new.py
```

## 📊 Data Management

### Syncing Functions and Images

The app includes two sync buttons in the sidebar for managing your data:

#### 📦 Sync Repository & Functions

This button syncs the repository, functions, and images:

1. **Repository Sync**: Updates the `coach-bot-repo` submodule to the latest version
2. **Pattern Extraction**: Automatically extracts filename patterns from repository functions
3. **Test File Parsing**: Scans test files to identify which functions are tested
4. **Image Scanning**: Scans test images from `coach-bot-repo/content/tests/` (generated by running tests)
5. **Image Organization**: Matches images to functions using extracted patterns
6. **Image Copying**: Copies matched images to `data/images/` folder
7. **Cache Refresh**: Automatically refreshes the display with updated data

**Prerequisites:**
- Tests must be run first to generate images: `cd coach-bot-repo && pytest src/content_generators/additional_content/stimulus_image/drawing_functions/tests/ -v`
- Images will be generated in `coach-bot-repo/content/tests/`

**When to use:**
- After running tests to generate new images
- When new functions are added to the repository
- When you want to update function patterns
- When test images have been regenerated

**Note:** The sync process does not run tests - it only scans images that were already generated by running tests. See `TEST_IMAGES_WORKFLOW.md` for details.

#### 📚 Sync Standards

This button updates educational standards from the database:

1. **Database Connection**: Connects to the MySQL database
2. **Standards Retrieval**: Fetches all educational standards for each function
3. **Stimulus Type Specifications**: Retrieves detailed specifications for each standard
4. **Data Update**: Updates local JSON files with the latest standards data
5. **Cache Refresh**: Automatically refreshes the display with updated standards

**When to use:**
- When standards have been updated in the database
- When new functions need standards linked
- Periodically to keep standards up to date

**Note:** Requires `DB_USERNAME` and `DB_PASSWORD` in your `.env` file.

### Manual Standards Update

You can also update standards from the command line:

```bash
python update_function_standards.py
```

This script uses concurrent processing (10 workers) for faster updates.

## 🎯 Educational Standards

The application integrates with educational standards databases to provide:
- **CCSS Standards**: Common Core State Standards for Mathematics
- **Function Mapping**: Links between functions and relevant standards
- **Stimulus Type Specifications**: Detailed specifications for each standard
- **Search Integration**: Find functions by searching for specific standards

## 🔧 Configuration

### Database Connection

The app connects to a MySQL database to fetch educational standards. Configure your database credentials in a `.env` file:

```env
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

### GitHub Token (Optional)

To sync the repository automatically:

```env
GITHUB_TOKEN=your_github_token
```

Get a token at: https://github.com/settings/tokens (needs `repo` scope for private repositories)

**Note:** If you don't have a token, you can set up the repository manually using SSH keys or other methods (see `SETUP_WITHOUT_TOKEN.md`).

### AI Search (Optional)

For enhanced search capabilities, add your OpenAI API key:

```env
OPENAI_API_KEY=your_openai_key
```
